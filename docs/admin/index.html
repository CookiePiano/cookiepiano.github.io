사이트 관리

CookiePiano 계정으로 GitHub에 로그인해 관리합니다. 초안을 저장해도 공개되지 않으며, 마지막 단계의 게시를 실행해야 홈페이지에 반영됩니다.

  1. 소개 편집 ↗

    이름과 홈페이지 소개를 한국어·영어로 함께 수정합니다.

  2. 저장소 편집 ↗

    소개할 공개 저장소와 설명, 순서, 대표 여부(featured), 기술 태그(tags)를 관리합니다.

  3. 이미지 업로드 ↗

    JPEG·PNG·WebP 정지 이미지, 파일당 10MiB·2,500만 화소 이하. 올린 뒤 저장소의 image 필드에 media/my-repository.jpg처럼 경로를 적습니다.

  4. 미리보기 생성 ↗

    Run workflow에서 main을 선택해 실행합니다. 완료된 작업의 preview 파일을 내려받아 확인합니다.

  5. 게시 ↗

    현재 초안 전체를 공개합니다. Run workflow에서 확인란을 선택하고 실행하면 몇 분 안에 반영됩니다.

공개 전에 확인하세요

저장소에 연결한 이미지와 작성한 내용은 게시하면 공개됩니다. 연결하지 않은 이미지와 초안 원본은 비공개 저장소에 남습니다. 한 번 공개한 자료는 Git 이력이나 방문자가 저장한 사본에 남을 수 있습니다.

이 안내 화면은 누구나 볼 수 있지만, 작업실과 작업 실행 권한은 GitHub가 제한합니다. 이 페이지에는 비밀번호나 토큰을 입력하지 않습니다.
